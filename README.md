🎵 SQL Music Store Analysis
📌 Project Overview
This project involves analyzing a music store database using SQL to extract valuable insights. The objective is to analyze sales trends, customer preferences, and inventory management using various SQL techniques such as JOINs, aggregations, subqueries, and window functions.

🚀 Key Objectives
Analyze sales trends to identify top-performing albums, artists, and genres.
Understand customer behavior by tracking purchases and preferences.
Optimize inventory management by identifying best-selling and least-selling items.
Utilize SQL queries to perform in-depth data analysis.
🔧 Tech Stack
Database: MySQL / PostgreSQL / SQLite (depending on availability)
Query Language: SQL
Tools: SQL Workbench / pgAdmin / DB Browser for SQLite
📂 Dataset Information
The database consists of multiple tables, including:

Customers – Stores customer details.
Invoices – Contains transaction details.
Invoice_Items – Tracks purchases within each invoice.
Tracks – Contains song details.
Albums – Stores album information.
Artists – Includes artist details.
Genres – Categorizes tracks by genre.
📊 SQL Techniques Used
✅ Data Retrieval & Filtering (SELECT, WHERE, ORDER BY, LIMIT)
✅ Joins (INNER JOIN, LEFT JOIN, RIGHT JOIN)
✅ Aggregation (COUNT, SUM, AVG, GROUP BY, HAVING)
✅ Subqueries & CTEs (WITH, Nested Queries)
✅ Window Functions (RANK(), DENSE_RANK(), ROW_NUMBER())

📈 Insights & Analysis
Top-selling artists and albums based on revenue.
Most popular genres among customers.
Highest-spending customers and their purchase trends.
Sales performance over time (monthly/yearly trends).
▶️ How to Run the Queries
Set up the database – Import the dataset into MySQL/PostgreSQL.
Use a SQL tool – Open MySQL Workbench, pgAdmin, or another SQL editor.
Run SQL queries – Execute scripts to analyze data.
